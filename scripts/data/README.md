# 실험 데이터

파일 이름: `날짜_흐름크기분포_전송방식_흐름수_client번호`

| 날짜 | 이름 | 내용 |
|---|---|---|
| 09/30 | `0930_VL2_bulkonly_500flows_*` | VL2 분포, 모든 흐름이 파일형(한 번에 쭉), GRO 켜짐 (패킷이 2896 등으로 합쳐져 기록됨) |
| 10/02 | `1002_VL2_3apps_100flows_*` | VL2 분포, 앱 3종(파일형/로그인형/영상형), GRO 꺼짐 (실제 1448 단위), 요청 20바이트 |

| 확장자 | 내용 |
|---|---|
| `.csv` | `pcap2csv.py` 결과: 흐름마다 크기(정답) + 앞쪽 패킷 10개의 크기·시간 |
| `.html` | 같은 CSV를 브라우저로 보기 좋게 (`csv2html.py`) |
| `_FCT.txt` | 트래픽 생성기가 남긴 흐름별 완료 시간 기록 (크기, 걸린 시간 µs, DSCP, rate, goodput) |
| 10/05 | `1005_VL2_clue<NNN>_1000flows_*` | 앱 3종, 단서 강도 0 / 0.5 / 0.8 / 1 (clue000 = 0, clue050 = 0.5 ...), 흐름 1000개, 마지막 요청 후 30초에 종료 (FCT 기록 없음) |

이름에 `_burst<B>_hist<HHH>`가 붙으면: 요청이 평균 B개씩 몰려옴, 직전 흐름과 같은 크기 구간을 고를 확률 HHH% (붙지 않으면 burst 1, hist 0).
